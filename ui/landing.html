Install

Get Acreo running in under a minute.

Acreo isn't on the Chrome Web Store yet, so you'll load it manually. Five steps, about 30 seconds.

Step 1

Download the code from GitHub

Go to the Acreo GitHub repository. Click the green Code button, then choose Download ZIP.

Step 2

Unzip the folder

Find the downloaded ZIP file in your Downloads folder and extract it. You should get a folder named Acreo-main. Remember where you put it — you'll point Chrome to this folder next.

Step 3

Open Chrome's extensions page

Type chrome://extensions into your address bar and hit Enter.

Step 4

Turn on Developer mode

Flip the Developer mode toggle in the top-right corner of the extensions page. This unlocks loading an extension that isn't from the Chrome Web Store.

Step 5

Click "Load unpacked"

A new button labeled Load unpacked will appear. Click it, then select the Acreo-main folder from step 2. Acreo will appear in your extensions list and start logging listings right away.
