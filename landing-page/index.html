The problem

House hunting shouldn't need a spreadsheet. Acreo builds it for you.

01 / Too many tabs

Every portal wants its own tab, and the flat you liked on Monday is gone by Wednesday.

02 / No common format

Each site shows price, area and deposit differently, so comparing means copying it all somewhere else.

03 / Seen it already?

Without a record of what you've opened, you end up reading the same listings again and again.

Privacy

Your shortlist stays yours. Nothing leaves your browser.

Everything Acreo collects is stored locally using chrome.storage.local. There is no backend to send it to.

Install

Up and running in about a minute.

Acreo isn't on the Chrome Web Store yet, so you'll load it yourself. Five quick steps, no technical knowledge needed.

Download from GitHub
  1. 01

    Download the code

    Open the Acreo GitHub repository, click the green Code button and choose Download ZIP.

  2. 02

    Unzip the folder

    Extract the ZIP from your Downloads. You'll get a folder named Acreo-main. Keep it somewhere you won't delete it.

  3. 03

    Open Chrome's extensions page

    Type chrome://extensions into the address bar and press Enter.

  4. 04

    Turn on Developer mode

    Flip the Developer mode toggle in the top-right corner. This lets Chrome load extensions from a folder.

  5. 05

    Click "Load unpacked"

    Select the Acreo-main folder. Acreo appears in your toolbar and starts collecting listings straight away.

FAQ

Questions, answered.

Is Acreo free?

Yes. There's no subscription, no account and no ads.

Which websites does it work with?

MagicBricks, 99acres and NoBroker, for both rentals and properties for sale. Acreo doesn't run on any other site.

Where is my data stored?

Only in your browser's local extension storage. Nothing is sent to a server, and Clear all removes everything in one click.

Why isn't it on the Chrome Web Store?

Not yet. For now you install it from GitHub using the five steps above, which takes about a minute.

I found a bug. How do I report it?

Open an issue on GitHub or send an email. Every report helps.
